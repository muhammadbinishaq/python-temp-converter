# Python Temperature Converter

## About the Project
This is a simple Python-based Temperature Converter that allows users to convert temperatures between Celsius and Fahrenheit. The program takes input from the user, performs the selected conversion, and displays the result.

## Features
- Convert Celsius to Fahrenheit.
- Convert Fahrenheit to Celsius.
- User-friendly menu with two conversion choices.
- Takes temperature input from the user.
- Displays the converted temperature.
- Allows users to perform multiple conversions without restarting the program.
- Provides an option to exit the program.

## Conversion Formulas
- **Celsius to Fahrenheit:** °F = (°C × 9/5) + 32
- **Fahrenheit to Celsius:** °C = (°F − 32) × 5/9

## Technologies Used
- Python 3

## How to Run
1. Install Python 3 on your computer.
2. Clone this repository or download the project files.
3. Open the project folder in VS Code.
4. Run the Python file using the terminal:

   ```bash
   python main.py
   ```

   Replace `main.py` with your actual Python filename if it is different.

5. Select the desired conversion option.
6. Enter the temperature value.
7. Choose whether to perform another conversion or exit.
